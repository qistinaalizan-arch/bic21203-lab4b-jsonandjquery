# bic21203-lab4b-jsonandjquery

## Description
This lab demonstrates JSON data structure,
JavaScript fetch(), and jQuery DOM manipulation.

## Files
- books.json - Contains book information in JSON format.
- books.html - Retrieves and displays JSON data.
- jquery-dom.html - Demonstrates jQuery DOM operations.

## How to Run
1. Download or clone this repository.
2. Open the folder using Visual Studio Code.
3. Install the Live Server extension.
4. Open books.html using Live Server.
5. Open jquery-dom.html in a browser.
6. Ensure an internet connection for the jQuery CDN.
